 🎮 Tic Tac Toe Gamez

A simple Tic Tac Toe game made using Python.

This project is created as a beginner-level project for a 1st year CSE student.

## 📌 About the Project

Tic Tac Toe is a two-player game.

- Player 1 uses `X`
- Player 2 uses `O`
- Players take turns choosing a position from 1 to 9.
- The first player to get three symbols in a row wins.
- If all positions are filled and nobody wins, the game is a draw.
